# Parking-management-system-01-main

## Setup / Installation

### 1. Clone the repository
```bash
git clone https://github.com/pranto2051/Parking-management-system-01-main.git
cd Parking-management-system-01-main
```

### 2. Install Node modules
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

### 4. Open in browser
```bash
http://localhost:3000
```

## If `npm run dev` does not work
Check `package.json` for the correct script name, then run one of these:

```bash
npm start
```

or

```bash
npm run serve
```
