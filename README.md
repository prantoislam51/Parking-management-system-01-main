## Full Setup / Installation Guide

### Prerequisites
- [Node.js](https://nodejs.org/) installed
- [Git](https://git-scm.com/) installed

### 1. Download the project
```bash
git clone https://github.com/pranto2051/Parking-management-system-01-main.git
cd Parking-management-system-01-main
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```

### 4. Open the app in browser
```bash
http://localhost:3000
```

## If the server does not start
Check `package.json` and use the correct script name:

```bash
npm start
```

or

```bash
npm run serve
```

## Common issues
- Make sure Node.js is installed
- Delete `node_modules` and `package-lock.json`, then run `npm install` again
- Check the terminal for missing environment variables or package errors
